# Institutional branding

The TU Braunschweig seal and IfN artwork were supplied for this institutional
demonstration. They are retained for the private publication repository at the maintainer’s request;
no unrestricted public redistribution or trademark permission is asserted.
Confirm separate permission before publishing the assets publicly.

`frontend/branding/logo_tubs.jfif` is the unchanged seal.
`assets/branding/logo_IFN.original.svg` preserves the original IfN SVG.
`frontend/branding/logo_IFN.svg` changes only its root width, height and viewBox
to trim whitespace; artwork paths, colors, lettering and transforms are retained.
The unused historical PNG is excluded. CSS preserves image aspect ratios.
Do not regenerate or reinterpret these institutional marks.
